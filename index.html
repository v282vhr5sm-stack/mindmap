빈 곳을 두 번 탭해서 시작하세요
펜슬로 쓰거나 · 손가락으로 탭해서 키보드로 입력
내 마인드맵
사용법
  • 빈 곳 두 번 탭 → 새 상자
  • 상자를 손가락으로 탭 → 키보드 입력 · 펜슬로 탭 → 손글씨
  • 엔터 또는 상자 밖을 펜슬로 터치 → 쓰기 끝
  • + 아래로 꼬리 잇기 · − 같은 줄에 상자 추가
  • 펜슬로 상자에서 다른 상자로 끌기 → 연결 (빈 곳에 놓으면 새 상자)
  • 손가락으로 상자 끌기 → 이동 · 빈 곳 끌기 → 화면 이동 · 두 손가락 → 확대/축소
  • 화살표를 탭 → × 로 연결 삭제
