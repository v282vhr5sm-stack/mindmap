빈 곳을 탭해서 시작하세요
펜슬로 쓰거나 · 손가락으로 탭해서 키보드로 입력
내 마인드맵
사용법
  • 빈 곳 탭 → 새 상자 (쓰는 중이면 쓰기 끝)
  • 상자를 손가락으로 탭 → 키보드 입력 · 펜슬로 탭 → 손글씨
  • 엔터 또는 상자 밖을 펜슬로 터치 → 쓰기 끝
  • + 아래로 꼬리 잇기 · − 같은 줄에 상자 추가
  • 펜슬로 상자에서 다른 상자까지 선을 그으면 연결 (빈 곳에서 끝내면 새 상자) · +를 끌어도 연결
  • 상자 이동: 손가락으로 끌기 · 펜슬은 꾹 누른 뒤 끌기 (다른 상자 위에 놓으면 그 상자에 꼬리로 연결)
  • 선택한 상자의 테두리 점(상하좌우·모서리)을 끌어 크기 조절 · 점을 탭하면 자동 크기
  • − 같은 줄 상자는 가로 줄이면 가로로, 세로 줄이면 세로로 정렬
  • 🖼 사진 추가 (상자를 선택해 두면 그 아래로 연결)
  • 빈 곳 끌기 → 화면 이동 · 두 손가락 → 확대/축소
  • 화살표를 탭 → × 로 연결 삭제
